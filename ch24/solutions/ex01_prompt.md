# 연습문제 1 풀이 예

고치기 전: "점수 처리하는 함수 만들어 줘."

고친 뒤:

- 목적: 시험 점수 목록에서 합격자 수를 세는 함수가 필요하다.
- 맥락: 파이썬 3.14. 표준 라이브러리만 쓴다. 점수는 0~100의 정수 리스트다.
- 요구: `count_passed(scores, cutoff=60)`은 cutoff 이상인 점수의 수를 돌려준다.
- 제약: 타입 힌트와 한 줄 독스트링을 단다. 입력 리스트를 바꾸지 않는다.
- 완료 조건: `count_passed([59, 60, 61]) == 2`, `count_passed([]) == 0`,
  `count_passed([70, 80], cutoff=75) == 1`이 통과한다.
